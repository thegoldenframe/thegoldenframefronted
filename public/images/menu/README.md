# Menu photos

Drop one photo per menu item in this folder. The cafe page loads it automatically.

File name = the item name in lowercase, with spaces and symbols replaced by "-" and ".jpg" at the end.

| Menu item            | File name                  |
|----------------------|----------------------------|
| Crispy Nachos        | crispy-nachos.jpg          |
| Loaded Fries         | loaded-fries.jpg           |
| Chicken Wings (6 pc) | chicken-wings-6-pc.jpg     |
| Classic Club Burger  | classic-club-burger.jpg    |
| Margherita Pizza     | margherita-pizza.jpg       |
| Cold Coffee          | cold-coffee.jpg            |
| Masala Chai          | masala-chai.jpg            |
| Brownie Blast        | brownie-blast.jpg          |

Tips: square photos (about 600 x 600 px), under 150 KB each. If a file is missing, the page shows the
illustrated tile instead, so you can add photos gradually.
